# micro-remote — 酷丁狐的科技實驗室

`index.html` 是整套教材的入口網，依主題分區：主題1 深海探險隊（遙控車、潛艇出航、深海探險、深海規則實驗室，第五～八堂）與主題A 機械手臂（機械手臂遙控、吊車遙控，第一～四堂），各附單元對照表，另有實驗步驟與故障排除。共用色票在 `kuding.css`，遙控器頁面套用 `remote.css`，遊戲頁面套用 `game.css`。

手機端網頁 App，透過 Web Bluetooth 直接控制使用 MakeCode「藍牙串口 (Bluetooth UART)」積木的
micro:bit 遙控車，搭配文件開頭截圖中的積木程式使用，不需另外安裝原生 App。

## 檔案結構

- `car.html` — 遙控車頁面與按鈕（前進／後退／左轉／右轉／停止）（原本的 `index.html`）
- `style.css` — 手機優先的深色介面樣式
- `app.js` — Web Bluetooth 連線與指令傳送邏輯
- `manifest.json` / `sw.js` / `icon.svg` — 讓頁面可「加入主畫面」成為類 App 使用

## 通訊協定

App 透過 micro:bit 內建的 **Nordic UART Service**（MakeCode 藍牙積木使用的同一組服務）傳送資料：

| 用途 | UUID |
| --- | --- |
| Service | `6e400001-b5a3-f393-e0a9-e50e24dcca9e` |
| RX（App 寫入 → micro:bit 讀取） | `6e400002-b5a3-f393-e0a9-e50e24dcca9e` |
| TX（micro:bit 通知 → App 顯示） | `6e400003-b5a3-f393-e0a9-e50e24dcca9e` |

每次按下方向鍵會送出「單一字元 + `#`」，對應積木程式中的
`藍牙串口 讀取直到 #`：

| 指令 | 對應動作 |
| --- | --- |
| `f#` | 前進（M1=50, M2=50） |
| `b#` | 後退（M1=-50, M2=-50） |
| `l#` | 左轉（M1=50, M2=-50） |
| `r#` | 右轉（M1=-50, M2=50） |
| `s#` | 停止 — **需自行在 micro:bit 程式加入這個判斷**，見下方說明 |

## micro:bit 端需要加入的積木

截圖中的程式沒有處理停止的情況。App 預設在放開按鈕時會送出 `s#`，
請在既有的「如果 / 那麼」堆疊最後加入一個：

```
如果 C = "s" 那麼
    設置馬達M1的速度為 0　馬達M2的速度為 0
```

若不想修改 micro:bit 程式，可以在 App 中關閉「放開按鈕自動停止」，
按鈕就只會在點擊當下送出一次方向指令（不會送出 `s#`），靠切換其他方向鍵來改變動作。

## 使用方式

1. 用手機瀏覽器開啟 `car.html`（需部署在 HTTPS 網址，例如 GitHub Pages；
   Web Bluetooth 不允許在一般 `http://` 網址下使用）。
2. 點右上角「連接」，在裝置選單中選擇對應的 `BBC micro:bit [xxxxx]`。
3. 連接成功後即可用畫面上的方向鍵操控遙控車，下方「通訊紀錄」會顯示送出與收到的資料，方便除錯。
4. 可用瀏覽器「加入主畫面」功能將頁面安裝成類似原生 App 的圖示。

### 瀏覽器相容性

Web Bluetooth 目前僅部分平台支援：

- ✅ Android：Chrome、Edge
- ✅ iOS：需使用 [Bluefy](https://apps.apple.com/app/bluefy-web-ble-browser/id1492822055) 這類支援 Web Bluetooth 的瀏覽器（Safari／一般 Chrome for iOS 不支援）
- ✅ 桌機：Chrome、Edge（需藍牙介面卡）
- ❌ Firefox、一般 iOS Safari

## 部署建議

最簡單的方式是啟用 GitHub Pages（Settings → Pages → 選擇此分支 / 根目錄），
即可取得 HTTPS 網址供手機開啟。

## 機械手臂遙控頁（arm.html）與吊車遙控頁（crane.html）

給「悟空機械手臂」課程用的兩個頁面，和遙控車共用同一套藍牙串口連線方式，`car.html` 不受影響。
GitHub Pages 網址後面加 `/arm.html` 或 `/crane.html`。每個按鈕送出「英文單字 + `#`」，
按住型的按鈕放開時自動送 `stop#`。

**arm.html（第三堂：固定式機械手臂）**

| 指令 | 按鈕 | 用法 |
| --- | --- | --- |
| `left#` / `right#` | 底座左轉／右轉 | 按住 |
| `up#` / `down#` | 手臂抬起／放下 | 按住 |
| `grab#` / `open#` | 夾爪夾緊／放開 | 點一下 |
| `stop#` | 停止 | 點一下 |

**crane.html（第四堂：吊車 = 小車底盤 + 全伺服手臂）**

| 指令 | 按鈕 | 用法 |
| --- | --- | --- |
| `forward#` / `back#` / `left#` / `right#` | 車子前進／後退／左轉／右轉（M1、M2） | 按住 |
| `spinL#` / `spinR#` | 轉台左旋／右旋（S1 連續伺服） | 按住 |
| `up#` / `down#` | 手臂抬起／放下（S0） | 按住 |
| `grab#` / `open#` | 夾爪夾緊／放開（S2） | 點一下 |
| `stop#` | 停止 | 點一下 |
| `rec#` / `play#` | 示教：開始錄製／重播（挑戰） | 點一下 |

micro:bit 端：`當藍牙串口收到資料 #` → `指令 = 藍牙串口 讀取直到 #`，再用「如果 指令 = "left"」等判斷。

## 深海探險（sub.html）— micro:bit 體感潛艇遊戲

電腦（Chrome／Edge）或平板開啟。側面視角的深海世界，有水的慣性與阻力：傾斜之後潛艇慢慢加速、慢慢停下。
沒有 micro:bit 時可用鍵盤方向鍵試玩、空白鍵發射聲納。畫面上有「上下相反」選項。

- **駕駛訓練（主題1 第六堂）**：左右傾斜前進／後退、前後傾斜下潛／上浮，90 秒收集發光珍珠。
- **雙屏尋寶（主題1 第八堂）**：寶藏藏在黑暗中，看 micro:bit 的雷達找；聲納 3 次；120 秒。

| 方向 | 訊息 | 意思 |
| --- | --- | --- |
| micro:bit → 電腦 | `x:數字`、`y:數字` | 加速度感測值（藍牙串口 寫入值），約每 0.1 秒送一次 |
| micro:bit → 電腦 | `p#` | 發射聲納 |
| micro:bit → 電腦 | `l#` `r#` `u#` `d#` | 舊版方向指令，也可以用 |
| 電腦 → micro:bit | `0#`～`4#` | 雷達強度，4 最近（尋寶模式） |
| 電腦 → micro:bit | `g#` | 收集到珍珠／找到寶藏 |
| 電腦 → micro:bit | `e#` | 時間到 |

## 深海規則實驗室（lab.html）

先用積木寫規則，再按「開始遊戲」下水。規則編輯和遊戲是兩個分開的畫面。

- 事件：當遊戲開始、每隔幾秒、當潛艇碰到（小魚／水母／鯊魚／珍珠／寶箱／水雷／氧氣泡）、撞到岩石、分數達到、倒數時間到、生命用完、按下按鈕 A、收到 micro:bit 訊息
- 動作：放出生物、移除、速度、分數、倒數、生命、畫面數值、潛艇馬力／大小、海流、亮度、聲納、雷達、說話、音效、特效、傳給 micro:bit
- 範例規則：第六堂珍珠收集／小心水母、第七堂黑暗尋寶／鯊魚出沒、第八堂雙屏尋寶／氧氣危機、自由創作
- 安全：迴圈超過次數會停用該規則；海裡最多 160 個生物；規則出錯只停用那一條，遊戲不會壞掉
- 規則自動存在瀏覽器，也可以「儲存檔案」／「開啟檔案」
- 沒有 micro:bit 時用方向鍵和空白鍵操作

## 潛艇出航 俯視海底（cockpit.html）

主題1 第五堂「潛艇出航」的電腦端：俯視角像素風海底，只照得到潛艇這一格，micro:bit 的 LED 當海圖。

- 網頁送出 f# b# l# r#（和潛艇遙控器相同），用同樣規則同步位置：起點 (0, 0)、邊界 0～4
- 網頁上沒有水雷：水雷只在 micro:bit 上。micro:bit 撞到水雷時送出 `boom#`，網頁收到才爆炸、潛艇回到 (0, 0)；水雷會搬到新的隨機位置（1～4）
- 海底幾乎全黑，只照得到潛艇附近，要看 micro:bit 的海圖避開水雷
- 發光珍珠只有網頁看得到；模式：自由巡航、限時尋寶 60 秒

## 潛艇遙控器（pilot.html）與聲納尋寶（sonar.html）

- `pilot.html`：主題1 第五堂的手機遙控器，送出 f# b# l# r#（不送停止），潛艇在 micro:bit 的 5×5 海底走一格
- `sonar.html` + `sonar.js`：主題1 第七堂的連動遊戲。10×10 海底只畫在電腦上；按方向鍵送 f、b、l、r（和第五堂相同），micro:bit 移動潛艇、算距離，再用「寫入值」送回 x、y（0～9）和 d（距離），找到寶藏送 found#。雷達閃燈（LED 長條圖，越近閃越快）在 micro:bit 上，嗶嗶聲由網頁照 d 發出。注意：micro:bit 連著藍牙時播聲音會當機（070，藍牙底層 SoftDevice 錯誤），所以 micro:bit 不播聲音。海裡有慢慢游的鯊魚。沒有 micro:bit 時可用方向鍵試開潛艇（沒有雷達）

## 主題2 聲音與感應（第五～八堂平板小遊戲）

四個遊戲共用 `mblink.js`（藍牙串口連線、`MB.send` / `MB.on`、音效 `SFX`）和 `mbgame.css`。
micro:bit 送出「名稱:數字」一行（MakeCode `藍牙串口 寫入數值`），平板回傳「單字#」。
專案要加入 **bluetooth** 擴展（會移除 radio），專案設定選「不需配對」。每台平板一次只能連一台 micro:bit。
沒有 micro:bit 時可用鍵盤試玩。參考程式在 `microbit/` 資料夾（MakeCode JavaScript，貼進 JavaScript 分頁即可轉成積木）。

| 頁面 | 堂次 | micro:bit → 平板 | 平板 → micro:bit | 鍵盤試玩 |
| --- | --- | --- | --- | --- |
| `flight.html` 酷丁狐飛行島（3D，Three.js 放在 `vendor/three/`） | 第五堂 | `x:`、`y:` 傾斜（轉彎、機頭上下），`d:` 超音波距離（油門，可不送） | `star#` 星星、`ring#` 圓環、`crash#` 撞到、`end#` 結束 | ← → ↑ ↓、W／S 油門 |
| `space.html` 超音波太空梭（舊版第五堂，保留） | — | `d:公分` | `star#`、`hit#` | ↑ ↓ 或滑鼠 |
| `sports.html` micro:bit 運動會 | 第六堂 | `x:加速度X`（傾斜瞄準）、`s:最大力道`（揮一下送一次，1500 以上算揮動） | `good#` 打得好、`miss#` 失誤 | ← → 瞄準，按住空白鍵蓄力 |
| `race.html` 旋鈕賽車（四條風格賽道；放開油門慢慢滑行，不會倒退） | 第七堂 | `k:旋鈕 0～1023`、`b:按鍵 0～5`（A 油門、B 煞車、C 氮氣） | `go#` 開始、`lap#` 一圈、`end#` 完賽 | ← → ↑ ↓、空白鍵氮氣 |
| `maestro.html` 體感指揮家 | 第八堂 | `beat#` 揮一下、`t:BPM`（自己算的速度）、`x:加速度X` | `bar#` 每小節、`end#` 演奏完畢 | 空白鍵打拍子、← → 傾斜 |

接線：超音波 P15（trig/echo 同腳）、旋鈕 P1、五鍵按鍵 P2；不需要蜂鳴器，聲音由 micro:bit V2 內建喇叭發出。

### 主題2 規則實驗室（積木改規則）

四個遊戲的選單都多一張「規則實驗室」卡片（也可以直接開 `space.html#lab` 這類網址）。
做法和深海規則實驗室一樣：先用積木寫規則，再按「開始遊戲」，遊戲照著規則跑；
範例規則選單裡有每一堂的標準玩法和進階玩法，規則會自動存在這台電腦，也能存成 .json 檔。

- `rulelab.js` / `rulelab.css`：共用的積木編輯器、事件、分數／時間／生命、儲存開啟（Blockly 只在打開規則實驗室時才載入）
- `space-lab.js`、`sports-lab.js`、`race-lab.js`、`maestro-lab.js`：每個遊戲自己的積木和範例
- 原本的玩法、`lab.html` 深海規則實驗室和其他舊頁面都沒有改動

| 遊戲 | 專屬事件 | 專屬動作（部分） |
| --- | --- | --- |
| 酷丁狐飛行島 | 當收集到星星、當穿過圓環、當撞到地面／海面 | 放出星星或圓環（小島上空、高空、前方、大山、海面）、天空（白天／黃昏／夜晚／大霧）、速度、加速、回到機場 |
| 超音波太空梭（舊版） | 當太空梭碰到（水晶／隕石／燃料罐／護盾泡泡／外星飛碟）、當 … 飛走了 | 放出、移除「它」、速度、護盾、太空梭大小、超音波範圍 |
| micro:bit 運動會 | 當揮動、當保齡球停下來、當擊中球、當沒打到球、當我／電腦得分 | 比賽項目、球瓶數、護欄、球速、電腦強度、變化球、彩帶 |
| 旋鈕賽車 | 當比賽出發、當跑完一圈、當車子碰到（金幣／香蕉皮／道具箱／加速板／油桶）、當開出跑道、當按下 D／E 鍵 | 在賽道放道具、加速、氮氣、打滑、極速、方向盤靈敏度、賽道、幽靈車 |
| 體感指揮家 | 當揮一拍、當每一小節開始、當進入第 N 小節、當指揮棒傾向左／右／中間、當樂曲結束 | 目標速度、聲部音量、舞台燈光、煙火、觀眾鼓掌、從頭再演奏一次 |

規則實驗室模式下，遊戲不會自動傳 `good#`、`lap#` 這些訊息給 micro:bit，要用「傳送給 micro:bit」積木自己決定什麼時候傳（範例規則裡已經寫好）。

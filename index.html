設定 micro:bit 端程式

本 App 會送出 f#、b#、l#、r# 分別代表前進／後退／左轉／右轉，對應你截圖中的四個「如果」積木，不需要修改。

但截圖的程式沒有「停止」的判斷，放開按鈕時 App 會送出 s#， 若沒有對應積木，馬達會維持最後速度。建議在最後加入一個「如果」積木：

如果 C = "s" 那麼
  設置馬達M1的速度為 0　馬達M2的速度為 0

若不想修改程式，可以把上方「放開按鈕自動停止」關閉， 按鈕就只會在點擊時送出一次方向指令，靠再次點擊其他方向來改變動作。
